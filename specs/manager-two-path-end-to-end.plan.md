# 技术经理人双路径端到端测试计划

## Application Overview

在隔离的本地数据库中，用两个独立技术经理人账号验证注册、平台认证、企业需求提交、项目推进、对接方登记、费用确认与结算的完整闭环，并在每个后台关键状态保存截图证据。

## Test Scenarios

### 1. 委托平台共同撮合

**Seed:** 访问隔离测试服务的 `/manager`，浏览器会话与数据库均为空。

#### 1.1. entrusted-platform-full-cycle

**Steps:**
  1. 技术经理人甲免费注册。
    - expect: 经理人端显示“认证审核中”。
    - expect: 后台认证列表出现该申请且状态为“待认证”。
  2. 管理员审核通过。
    - expect: 后台状态变为“已认证”。
  3. 经理人甲选择“委托平台匹配”并提交企业技术需求。
    - expect: 后台项目列表出现新项目且状态为“待平台审核”。
  4. 管理员受理并进入匹配。
    - expect: 后台项目状态依次可保存为“已受理”和“匹配中”。
  5. 管理员登记平台找到的技术对接方并推进对接。
    - expect: 后台显示对接方来源为“平台登记”。
    - expect: 项目状态可进入“已建立技术对接”和“对接中”。
  6. 管理员登记成交和分成结算。
    - expect: 项目状态为“已成交”。
    - expect: 结算类型为“平台撮合分成”，状态为“已结算”。

### 2. 技术经理人自主联系对接

**Seed:** 使用第二个全新浏览器会话访问隔离测试服务的 `/manager`。

#### 2.1. manager-self-service-full-cycle

**Steps:**
  1. 技术经理人乙免费注册并由管理员认证。
    - expect: 后台认证列表完整显示申请与审核结果。
  2. 经理人乙选择“自主联系对接”并提交企业技术需求。
    - expect: 后台项目列表出现新项目，服务费状态为“免费阶段”。
  3. 管理员审核受理项目。
    - expect: 经理人端出现“登记自主对接进展”入口。
  4. 经理人乙登记其自行找到的技术资源和阶段进展。
    - expect: 后台显示对接方来源为“经理人自主登记”。
    - expect: 服务费状态自动变为“待确认”。
  5. 管理员确认少量平台服务费并登记支付。
    - expect: 服务费状态可从“待确认”进入“待支付”再进入“已支付”。
  6. 管理员登记自主对接服务费结算并完成项目。
    - expect: 项目状态为“已成交”。
    - expect: 结算类型为“自主对接服务费”，状态为“已结算”。

## Evidence Plan

- 每个后台关键阶段保存一张当前运行生成的 PNG 截图。
- 截图必须包含对应经理人或项目编号、状态、服务方式、费用状态或结算记录中的至少一项可核验证据。
- 每张截图保存后单独打开检查；错误窗口、加载中、裁切关键字段或空白截图一律重拍。
